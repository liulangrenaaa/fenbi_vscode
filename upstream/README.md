# 隐私说明

排行榜会在新交卷的客观题解析页上报粉笔昵称、经过 SHA-256 处理的用户标识、答题记录标识、交卷时间、本次实际答题量及答对题数。榜单公开展示昵称、当日累计答题量和胜率。不会向排行榜服务发送粉笔 Cookie、账号密码、题目内容或具体答案。

# 今日排行榜

首页点击「排行榜」可切换答题量榜和胜率榜。按北京时间自然日累计，两个榜单均忽略当日累计答题量不足 10 题的用户；不足 10 题的练习仍会累计。胜率按当日答对总数 / 当日实际答题总数计算，不对各次练习的胜率取平均。

两个榜单各展示前 150 名，每页 50 人，最多 3 页。列表在可用区域内滚动，表头和底部页码保持可见；未进入前 150 名的用户仅显示“未上榜”，不展示具体名次。

普通练习、快速练习、智能组卷、历年试卷和错题练习的客观题交卷后自动上报。未作答题目、申论及面试不参与统计。查看历史解析不触发上报，同一练习重复上报不会累计；失败时可在结果页重试。

`fenbiTools.leaderboardApiUrl` 指定排行榜服务地址，默认使用已部署的 `https://qipai.work/fenbi-api`，供多个客户端共享当日榜单。本地联调可改为 `http://127.0.0.1:3102`。服务端代码位于 `majiang-miniprogram` 工程的 `server/fenbi`，部署步骤见该目录的 README。

部分网络会在该域名的 SNI 握手阶段断开连接；客户端遇到握手重置时会尝试一次不发送 SNI 的 HTTPS 连接，并继续严格验证证书链和 `qipai.work` 主机名，无需关闭证书校验。

专项验证：`npm run test:leaderboard`。
